# stūdio downloads

Installers for stūdio, a desktop app for Windows.

**[Download for Windows](https://github.com/cameronxmills/studio-releases/releases/latest/download/Studio-Setup-x64.exe)** (Windows 10 and 11, 64-bit)

## Install

1. Open `Studio-Setup-x64.exe`.
2. Windows may show a blue box that says "Windows protected your PC". Click **More info**, then **Run anyway**. The installer is not signed yet.
3. stūdio installs for your user and opens. It needs no administrator rights.

Each release lists the SHA-256 of its installer. Older versions are on the [releases page](https://github.com/cameronxmills/studio-releases/releases).
